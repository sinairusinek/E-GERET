# אגרת · סביבת לימוד — הסדנה לתיוג הטקסט

סביבת לימוד אינטראקטיבית בעברית לתיוג, תיעוד והעשרה של טקסטים, שנבנתה עבור בית הספר
**"מעבר למילים": מתודולוגיות חישוביות לניתוח טקסט** — DHSS Hub, האוניברסיטה הפתוחה, קיץ 2026.

**האתר החי:** https://sinairusinek.github.io/E-GERET/

## מה יש כאן

| תיקייה | תוכן |
|---|---|
| [`lab/`](lab/) | מפגש ראשון — מטקסט פשוט ל־Markdown, ל־HTML, ל־XML ול־TEI: מעבדת תיוג בארבעה שלבים עם אשף TEI מודרך |
| [`lab2/`](lab2/) | מפגש שני — זיהוי ישויות (NER), קישור ל־Wikidata ולגזטיר Kima, קבצי זהויות (standOff) ונתונים פתוחים מקושרים |
| [`assets/`](assets/) | קבצים משותפים |

כל מעבדה היא קובץ HTML עצמאי אחד: כל הקוד רץ בדפדפן, ללא שרת וללא מפתחות API.
הטקסטים לדוגמה — מכתבים מ[פרויקט בן־יהודה](https://benyehuda.org/), ובמרכזם מכתבו של
א"א קובנר לראובן בריינין (1904).
